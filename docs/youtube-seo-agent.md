# Агент для YouTube SEO на базе сценария ролика

## Цель
Сделать агента, который принимает текст сценария YouTube-видео и генерирует готовый SEO-пакет:
- заголовки (несколько вариантов);
- описание (с ключевыми словами и таймкодами);
- теги;
- хэштеги;
- главы (chapters);
- закреплённый комментарий;
- идеи для превью (thumbnail text).

## Рекомендуемый pipeline
1. **Вход**: полный сценарий + язык + ниша + целевая аудитория.
2. **Извлечение смысла**: тема, интент, ключевые тезисы, сущности.
3. **Семантика**: первичный ключ, вторичные ключи, long-tail фразы.
4. **SEO-генерация**: title/description/tags/hashtags/chapters.
5. **Валидация**: проверка на переспам, кликабельность и соответствие контенту.
6. **Выход**: структурированный JSON + человекочитаемый вариант.

## Формат входа
```json
{
  "language": "ru",
  "niche": "маркетинг",
  "audience": "предприниматели и маркетологи",
  "goal": "увеличить CTR и удержание",
  "script": "...полный текст сценария..."
}
```

## Формат выхода
```json
{
  "primary_keyword": "...",
  "secondary_keywords": ["...", "..."],
  "titles": ["...", "...", "..."],
  "description": "...",
  "tags": ["..."],
  "hashtags": ["#..."],
  "chapters": [
    {"time": "00:00", "title": "..."}
  ],
  "thumbnail_ideas": ["...", "..."],
  "pinned_comment": "...",
  "seo_score": 0,
  "notes": ["..."]
}
```

## Правила SEO для YouTube (практический минимум)
- **Title**: 55–70 символов, главный ключ ближе к началу, без кликбейта вне содержания.
- **Description**:
  - первые 1–2 предложения должны содержать главный ключ и обещание ценности;
  - 150–300 слов с естественным вхождением вторичных ключей;
  - CTA (подписка/комментарий/переход по ссылке);
  - при необходимости — таймкоды.
- **Tags**: 10–20 релевантных, mix из высоко- и низкочастотных.
- **Hashtags**: 3–5 релевантных (# без переспама).
- **Chapters**: логичные блоки, короткие и понятные названия.
- **Consistency**: ключевые слова должны совпадать в title + description + tags.

## Системный промпт для агента
```text
Ты — Senior YouTube SEO Strategist.
Твоя задача: по сценарию ролика сгенерировать SEO-пакет для YouTube.

Ограничения:
1) Не придумывай факты, которых нет в сценарии.
2) Пиши естественно, без переспама ключами.
3) Дай 3 варианта заголовка с разной стратегией:
   - поисковый (search intent),
   - кликабельный (CTR),
   - экспертный (authority).
4) Сформируй:
   - primary_keyword,
   - 8-15 secondary_keywords,
   - description (150-300 слов),
   - 10-20 tags,
   - 3-5 hashtags,
   - chapters,
   - pinned_comment,
   - 3 идеи текста для thumbnail.
5) Оцени результат по шкале 0-100 (seo_score) и добавь notes с улучшениями.
6) Верни ответ строго в JSON.
```

## User prompt-шаблон
```text
Язык: {{language}}
Ниша: {{niche}}
ЦА: {{audience}}
Цель: {{goal}}

Сценарий ролика:
{{script}}
```

## Критерии качества (чеклист)
- Главный ключ явно считывается из сценария.
- Заголовки различаются по стратегии, а не только по словам.
- Описание помогает ранжированию и удержанию.
- Нет "мусорных" тегов, не связанных с видео.
- Рекомендации применимы «как есть» — можно сразу вставлять в YouTube Studio.

## Техническая реализация (быстрый старт)
- Храни вход/выход в JSON.
- Делай отдельный шаг валидации (можно вторым вызовом модели).
- Добавь ограничение по длине полей (title, description и т.д.).
- Логируй результат и seo_score для A/B тестов.
